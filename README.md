# Travel Handbook Skill

把“帮我做一份旅行攻略”变成一份可以真正打开、查看和执行的个性化旅行手册。Skill 会研究目的地信息，安排每日路线，并生成网页、地图、餐饮建议、准备清单和实用提示。

## 它能做什么

- 根据你的目的地、日期、人数、节奏和兴趣规划每日行程
- 按区域、开放时间、预约安排和移动负担整理路线
- 生成真实道路路线地图和地点导航入口
- 整理景点、餐厅、当地体验、购物和语言信息
- 生成带复选进度的准备清单
- 输出适合手机和电脑查看的 HTML 旅行手册
- 通过网页按钮打印/保存 PDF，并保留当前页面的勾选状态、封面背景、图片和地图

## 第一次使用：小白流程

### 1. 下载 Skill

下载或 Clone 本仓库。将包含 `SKILL.md`、`assets/`、`references/` 和 `scripts/` 的整个文件夹放入你使用的 Agent 的 Skills 目录。

不要只复制 `SKILL.md`，问卷、模板和渲染脚本也需要一起保留。

如果你不熟悉下载和安装，也可以把下面这段提示词直接发给支持从 GitHub 安装 Skill 的 AI：

```text
请从这个 GitHub 仓库下载并安装旅行手册 Skill：
https://github.com/T1ffanyOvO/travel-handbook-skill

请安装整个 Skill 文件夹，不要只复制 SKILL.md。
安装后检查 SKILL.md、assets、references、scripts 和 agents 是否都已保留，并告诉我实际安装位置。
```

如果 Agent 支持直接安装 GitHub Skill，它会完成下载和放置；如果不支持，请按照上面的手动方式操作。

### 2. 重新打开 Agent

安装完成后，重新打开一个任务或对话，让 Agent 重新读取 Skill。

### 3. 发送旅行需求

可以直接发送完整需求，例如：

```text
使用 $travel-handbook，为我制作一份巴黎 6 天旅行手册。
两个人，节奏轻松，喜欢美食、拍照和街区漫步。
```

也可以替换成你的真实目的地和偏好。

### 4. 信息不完整时填写问卷

如果还没有提供足够信息，Agent 会打开内置的 HTML 问卷。填写目的地、日期或天数、人数、节奏、预算和兴趣后，点击“整理手册需求”，复制页面生成的提示词，再发回给 Agent。

如果已经订了机票或酒店，可以在“其他说明”中填写航班号、酒店名称、入住日期和其他已确认信息。

问卷内容只保存在当前浏览器的本地存储中，不会自动上传到服务器。

## 最终会得到什么

- `index.html`：可以直接用浏览器打开的旅行手册网页
- `destination-profile.json`：网页和 PDF 共用的结构化旅行数据
- `map-snapshots/`：每天一张真实道路路线地图截图
- PDF：点击网页中的“一键打印/保存 PDF”生成，不提供静态 PDF 下载文件
- 来源、核验日期和地点信息：保留在结构化数据中

网页是主要交付物。点击“一键打印/保存 PDF”后，浏览器会打开保存为 PDF 的流程；网页会保留当前设备上的清单勾选状态。动态信息无法可靠确认时，手册会使用保守表达，并提示出发前复核，不会编造开放时间、价格或预约结果。

## 地图服务

Skill 只使用两类用户导航入口：

- 海外目的地默认使用 Google Maps
- 中国大陆目的地默认使用高德地图

路线截图在生成阶段完成，不依赖用户打开网页时实时加载地图。具体规则见 [`references/map-provider.md`](references/map-provider.md)。

## 巴黎示例

仓库中的 [`docs/`](docs/) 是一份完整的巴黎旅行手册示例，包含 HTML、PDF、结构化数据、地图截图和路线报告。

如果配置了 GitHub Pages，可以直接通过 Pages 地址打开交互式网页；GitHub 文件页面本身只展示源码，不会直接运行 HTML。

## 常见问题

### 找不到问卷

手动打开 `assets/intake-questionnaire/index.html`，填写后把页面生成的提示词发给 Agent。

### 图片没有使用泛图

地点、餐厅、商店和体验优先使用准确实体图片。无法确认图片对应具体地点时，会保留待核验状态，不用无关图片冒充。

### 开放时间或价格不确定

动态信息以官方页面为优先，并保留核验日期。距离出发较远或无法可靠确认时，使用“出发前复核”等保守表达。

### 如何发布巴黎示例

在 GitHub 仓库的 `Settings → Pages` 中选择 `Deploy from a branch`，分支选择 `main`，文件夹选择 `/docs`，保存后等待 GitHub Pages 发布。

## 仓库结构

```text
SKILL.md                    Skill 入口和核心规则
assets/                     HTML 问卷和页面资源
references/                 数据、地图、输出和产品规范
scripts/                    渲染、地图生成和辅助脚本
docs/                       可直接发布的巴黎旅行手册示例
examples/                   示例数据和生成素材
agents/                     Agent 的 Skill 元数据
```
